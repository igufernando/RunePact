# Contributing / Como contribuir

## Commit convention / Convenção de commits

Every commit is bilingual and uses English first followed by Portuguese. Keep each language on a separate line in the body when more detail is needed.

Todo commit é bilíngue e usa inglês primeiro, seguido do português. Mantenha cada idioma em uma linha separada no corpo quando precisar de mais detalhes.

Example / Exemplo:

```text
feat: establish RunePact gameplay prototype

Adds the Unity project, combat rules, approved art, and bilingual project guidance.
Adiciona o projeto Unity, as regras de combate, a arte aprovada e as diretrizes bilíngues do projeto.
```

Use conventional prefixes such as `feat`, `fix`, `docs`, `refactor`, `test`, `build`, and `chore`.

Use prefixos convencionais como `feat`, `fix`, `docs`, `refactor`, `test`, `build` e `chore`.

## Pull requests and documentation / Pull requests e documentação

Describe gameplay impact, test evidence, and affected player-facing Portuguese text. Keep technical and design documentation bilingual.

Descreva o impacto no gameplay, a evidência de teste e os textos em português voltados ao jogador que foram afetados. Mantenha a documentação técnica e de design bilíngue.
